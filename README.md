# VestTrack

Plataforma pra organizar estudos pro vestibular. Fiz pra parar de usar planilha e caderno espalhado.

## o que tem

- landing page simples em `/` e app em `/app`
- dashboard com progresso, materias, tarefas
- 10 materias com topicos e checklist
- simulados com notas por materia
- pagina Hoje com metas diarias
- 500 questoes com pratica e quiz
- funciona sem login, salva no navegador
- opcional: sync na nuvem com Supabase

## stack

React + TypeScript + Vite + Tailwind + shadcn/ui

## rodar local

```bash
npm install
npm run dev
```
