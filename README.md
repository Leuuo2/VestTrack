# VestTrack

VestTrack is a study management platform designed to help students prepare for university entrance exams by organizing study schedules, tracking study hours, and monitoring learning progress.

## Goals

- Help students stay organized.
- Improve study consistency.
- Track progress over time.

## Planned Features

- [ ] User authentication
- [ ] Study schedule
- [ ] Study hour tracking
- [ ] Weekly goals
- [ ] Performance dashboard
- [ ] Flashcards
- [ ] Practice exams
- [ ] AI-powered study recommendations
